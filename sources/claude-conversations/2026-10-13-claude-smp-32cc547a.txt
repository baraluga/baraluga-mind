## Design: `india_iex_rtm_realtime` DAG (smp-india)

**Three pieces of existing code do most of the work:**
- **The HPX RTM DAG** ([india_hpx_national_dags.py](../smp-india/dags/src/india/india_hpx_national_dags.py)) already runs a scraper inside Airflow and publishes to TSDB with a read-back check. That's the template.
- **`smp_common.tsdb.publish_batch`** skips values that haven't changed. So polling every minute doesn't mean writing every minute, and the number of rows written tells us whether new prices arrived.
- **`write_india_iex_tsdb_expanded_parquet(RTM_TARGETS)`** plus the upload tasks already produce the parquet Grafana reads. Reusing them means Athena and the dashboards need no changes.

**How it works (DAG runs every minute, one run at a time, paused on creation):**

| Task | What it does |
|---|---|
| `collect` | Calls the IEX API using the current scraper's retrieval plan (latest blocks plus a 6-hour look-back to pick up corrections). The provider code is ported from `apac-tsdb-scraper`. |
| `publish` | Calls `publish_batch` with read-back, so CDH is only refreshed once TSDB can actually be read. If nothing was written, the run stops here (most runs). |
| `refresh_cdh` | Runs the existing RTM parquet writer and upload, about 48 times a day (only when new data arrives). |

**Expected delay:** up to 60s waiting for the next poll, about 3s to fetch, about 5–10s to write and read back from TSDB, about 30s to build the parquet, about 1s to upload, then Grafana's 1-minute refresh. That's **about 2–3 minutes worst case**, before Athena (not yet measured). This fits within 5 minutes.

**What gets retired:**
- `iex_api_national_rtm` (and possibly `iex_api_rtm`) in the `apac-tsdb-scraper` Lambda

**What 1 minute costs** compared with 5 minutes:
- About 1,440 Airflow runs a day instead of 288. Most of these do nothing and stop after `publish`.
- About 5 times more IEX API calls.
- TSDB writes stay the same, because unchanged values are skipped.

**Options in between, if the Airflow load worries you:**
- **Every 2 minutes:** worst case about 3.5–4 minutes. That still meets the target with a smaller margin.
