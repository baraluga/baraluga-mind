```bash
cd /Users/qn5792/repos/smp/smp-japan && .venv/bin/python - <<'EOF'
# Read-only: list TSDB versions of OCCTO interconnector Available Capacity for delivery D..D+2 (JST).
from uuid import uuid3, NAMESPACE_DNS
import pandas as pd
from engie_tsdb.catalog import Config
from engie_tsdb.data import read_ts

R = [("Hokkaido","Tohoku"),("Tohoku","Tokyo"),("Tokyo","Chubu"),("Kansai","Chugoku"),
     ("Kansai","Shikoku"),("Chugoku","Shikoku"),("Chugoku","Kyushu")]
IDS = {str(uuid3(NAMESPACE_DNS, f"OCCTO/{a}-{b}:Interconnection, Available Capacity")): f"{a}->{b}"
       for p in R for a, b in (p, p[::-1])}
today = pd.Timestamp.now(tz="Asia/Tokyo").normalize()
Config.set(catalog_endpoint="prod", client_name="d2_version_check", log_level="WARNING",
           read_data_methods=["api", "athena"])  # no creds -> interactive Okta login
df = read_ts(timeseries=list(IDS), start_application_date=today.tz_convert("UTC"),
             end_application_date=(today + pd.Timedelta(days=3)).tz_convert("UTC") - pd.Timedelta(microseconds=1),
             start_forecast_date=(today - pd.Timedelta(days=4)).tz_convert("UTC"),
             end_forecast_date=pd.Timestamp.now(tz="UTC"),
             columns=["*"], drop_duplicates=False, max_rows=1_000_000)
print(f"now JST {pd.Timestamp.now(tz='Asia/Tokyo'):%Y-%m-%d %H:%M}; {len(df):,} rows")
if df.empty:
    raise SystemExit("NO ROWS at all for D..D+2 -> real problem")
df["series_id"] = df.series_id.astype(str)
df["route"] = df.series_id.map(IDS)
df["day"] = pd.to_datetime(df.application_date, utc=True).dt.tz_convert("Asia/Tokyo").dt.date
df["version"] = pd.to_datetime(df.forecast_date, utc=True).dt.tz_convert("Asia/Tokyo").dt.strftime("%m-%d %H:%M")
# Full-day versions = one forecast_date covering all 48 half-hours of a day.
v = df.groupby(["day", "route", "version"]).size().rename("pts").reset_index()
full = v[v.pts >= 46]
print("\nFull-day versions per delivery day (JST version stamps):")
print(full.groupby(["day", "route"]).version.apply(", ".join).unstack(0).fillna("-").to_string())
d2 = (today + pd.Timedelta(days=2)).date()
ok = full[full.day == d2].route.nunique()
print(f"\nVERDICT D+2 {d2}: {ok}/{len(IDS)} routes have a full-day version ->",
      "FINE" if ok == len(IDS) else "MISSING, check the afternoon run")
EOF
```

**What it does:** it asks you to log in to Okta once in the browser. Then it runs one read-only query against prod TSDB, which should finish in well under a minute. It prints a table for today, D+1 and D+2: one row per route, one column per delivery day, listing every version that covers a full day.

**How to read it:** if Carlos is right, the last line says `VERDICT D+2 2026-10-16: 14/14 … FINE`, and that column shows a version stamped Oct 14. If it says `MISSING`, the table shows which routes have no version, so we know where to look.

**What I checked:** the 14 series IDs match the tags in Carlos's chart (`de4a6…`, `c0efc…`, `93ffd…`). I ran the script on fake data with one route missing D+2, and it flagged that route correctly.

**Not tested against real TSDB:** that needs the VPN. One risk is that the query has no time limit, because macOS doesn't come with `timeout`. If it hangs, Ctrl-C it.
